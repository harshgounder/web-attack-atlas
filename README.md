# web-attack-atlas

The thinking layer for web platform attacks. Companion to [`ai-web-arsenal`](https://github.com/),
which owns tools, installs and drivers. This repo owns patterns, preconditions, oracles, edge cases,
chains and counters.

Organising principle: **state mutation**. Not vulnerability class. Impact is a write.

Read `SCOPE.md` first. Then `patterns/` for the rendered atlas, `data/atoms.json` for the 16
primitives, `waves/QUEUE.json` for what is built and what is next.

## The gate

A pattern ships only when it answers all five:

1. what state changes
2. as whom
3. does it persist
4. how do you know it worked, and what is the negative control
5. what stops it, as a counter with its own precondition and cost

Run the gate:

```bash
python3 scripts/render-patterns.py --check
```

## Boundary

Knowledge and decision support for authorised security work. Every pattern carries its authorisation
precondition. No target-specific exploitation against systems the operator does not own or have written
permission to test.
